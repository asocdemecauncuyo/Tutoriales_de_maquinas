De forma general imprimimos en PETG y PLA, usamos OrcaSlicer para slicing, y controlamos la impresión con Octoprint que corre en una Raspberry que se conecta por USB a la impresora.
* Ver [el procedimiento](./procedimiento.md) de uso de la impresora para entender el flujo general.
* Ver el [archivo de info](./info.md) para conocer las specs generales de la impresora junto con links a la wiki de la impresora.
* Ver [las aplicaciones](./apps-y-archivos-requeridos.md) y archivos que son necesarior para el flujo general, que incluyen al Slicer y los archivos de perfil de la impresora y material, o el cliente de VPN cuando se quiere hacer el control remoto.
* Ver [el archivo de tensionado de las correas](./belt-tension.md) para el procedimiento de ajuste de las correas.
* Ver el [archivo para control manual](./control-con-lcd.md) para el uso de la impresora directamente a través del control manual (perilla al lado de la pantalla LCD que permite seleccionar menus de movimiento o de control de temperatura, etc.).
* Ver el [archivo de nivelación](./nivelacion.md) que describe el procedimiento para nivelación de la cama caliente utilizando un papel.
